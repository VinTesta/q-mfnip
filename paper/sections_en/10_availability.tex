\section*{Code and Data Availability}
The code, the experiment records, and the notebooks that produce every figure and table are publicly available at \url{https://github.com/VinTesta/q-mfnip}. The code is a Python package with a locked environment (\texttt{uv.lock}), and every number in Section~\ref{sec:results} is read from files written by the notebooks. The repository contains the package (\texttt{src/qmfnip/}), the validation tests of Section~\ref{sec:method-validation} (\texttt{tests/}), one notebook per experiment (\texttt{notebooks/}), and one output folder per experiment with its manifest, environment, instances, run records, summaries, and the identifier of the hardware job (\texttt{outputs/}). It also contains the experimental protocol with its log of deviations, the list of reported results with the file each number comes from, and the queries of the literature search (\texttt{docs/}).
